# NiyamCart Brand

## Product name

**NiyamCart**

## Tagline

**AI shopping, within your rules.**

## One-line description

NiyamCart is a bounded AI shopping agent that discovers products, explains recommendations, builds an exact cart, and hands payment to a human-approved Razorpay test checkout.

## Naming rules

- Use `NiyamCart` in all buyer-facing and merchant-facing UI.
- Use `BoundedCart` only as the internal repository/folder name where needed.
- Do not display `Kavach Saathi`, its logos, security vocabulary, or unrelated feature names in the new product.
- Do not imply Razorpay endorsement; describe Razorpay as the test-mode payment provider.

## Visual direction

- Commerce-first, friendly, and trustworthy.
- Clear approval boundaries around cart and payment actions.
- Avoid fear-heavy cybersecurity styling inherited from the source project.
- Keep the audit trail understandable to non-technical judges.
